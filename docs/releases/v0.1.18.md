## Queue, radio and For you

* For you now reflects what you have actually played recently. The profile decays by recency and adds a daily genre and mood view, so today's breakcore or sad listening shows up as today's recommendations instead of the all time favourite mix.
* The queue and radio now follow the song that is playing. The currently playing track anchors every refill, and the server clusters its genre and mood tags with the anchor, so a breakcore song keeps the queue in breakcore and a sad song keeps it sad.
* The same song can no longer come back as a slowed, sped up, remix, tekk, nightcore or reupload cut. The shared remix family key is computed in Rust for both the queue and the recommendation server, and each cut is limited to one appearance per batch.
* Artists can appear at most once per radio batch (twice for the anchor artist) and song families at most once, so the queue does not stack one creator.
* Trending now and Top chart keep using real YouTube Music charts for the selected region with iTunes and Last.fm fallbacks.

## Rust taste engine

* The listening profile, recency weighting, remix family keys and genre/mood tags now run in Rust through a new taste endpoint. The renderer only sends its recent history and favourites and renders the result, which trims script work and keeps the queue logic in one place.
* Genre and mood tags come from the track and artist text plus Last.fm, cached for a day. Genre names are canonicalised, so drum and bass, dnb and drum & bass count as the same vibe.

## Lighter and smoother

* Artwork on lists lazy loads, so covers only decode when they are about to be seen.
* Backdrop blur is capped at a cheap radius and the largest ambient blur layers were reduced. This cuts compositor tile memory and GPU cost while keeping the frosted look.
* The renderer runs a full garbage collection between frames only when audio is idle, and the queue panel refresh slowed from 700 ms to 1.5 s, so scrolling and playback stay responsive.
* The history list is capped at 60 tracks, which lowers retained script memory.

## Self update

* Riff Rust checks our own GitHub releases on every launch and silently downloads and installs a newer build, then relaunches on its own. Every update is hashed and verified before it installs.
* Version 0.1.18 is the first release of the Rust taste engine and the genre matched radio, so the auto update is the easiest way to get it.

## Player

* Playback errors still show a short readable message, and the stream recovery path retries a failed track instead of leaving a dead player.
