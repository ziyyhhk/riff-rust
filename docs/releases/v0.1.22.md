## Riff Rust 0.1.22

Smart Shuffle v2. Shuffle now has a sparkle button of its own next to the normal shuffle control, in the player, the mini/TV player and every playlist header. It picks randomly like shuffle, but it will not play the same artist twice in a row and it spreads the last few artists apart instead of clustering them. Playlists respect it too: with smart shuffle on, Play starts on a random track and each next track is chosen randomly rather than following the list order. The normal shuffle button still works exactly as before.

Hover to preview. Hover a track row and after a short delay Riff plays 15 seconds of it without touching the queue or the now-playing state. The snippet starts around 40 percent into the track (clamped so a full 15 seconds fits), which is usually past the intro and into the hook. Moving away stops it immediately. Because resolving a preview can cache the stream on disk, Riff asks the backend to delete that preview cache three minutes later. Tracks you already had offline, and local library files, are never deleted by a preview.

Storage auto-clear. Settings, Storage now has two timers: Clear cache every (default 7 days) and Clear offline library every (default 30 days), each with a Never option. The Rust backend reads those settings on startup and every six hours, clears the cached tracks folder when a timer is due, and records the last run so restarting the app does not wipe anything early. The first run after updating just seeds the timestamps.

Startup download progress fixed. The yt-dlp and ffmpeg auto-download used to report 100 percent from the moment the app opened and sit there until the real download finished. It now starts at 0 percent and only reaches 100 when the tools are actually done.

Updater UI. There is a full update window now: a sidebar with Changelog, Update Settings and Update History, the current and latest versions in the footer, and Cancel, Update Now and a new Skip version button. Skip remembers the exact version it skipped, so that release will not prompt again. Update Settings can check automatically and optionally install automatically. Update History keeps the last 25 installs locally. The window still uses the existing installer underneath and falls back to the GitHub release feed because this port has no release API wired up yet.

Memory and disk. The new features are idle-cheap by design: one reusable Audio element for previews that is emptied when it stops, timers only while hovering, and no new polling loops. Measured the same way as before (`npm run measure`), the main `riff-rust.exe` process sits around 3 to 6 MB and the whole WebView2 tree idles roughly 20 to 50 MB depending on what cached, spiking during load and playback. The OS browser remains the floor, so a guaranteed under-20 MB whole tree is still not a real claim; the app process itself is a few MB.

Installer is unsigned current user, same NSIS setup as before.
