## Riff Rust 0.1.25

Repeat now loops the current queue. With a playlist of two tracks, finishing the second track goes back to the first instead of handing the queue to random autoplay. Enabling repeat also drops autoplay tracks that were buffered ahead of the current song, so the loop stays on the playlist you chose.

The two storage cleanup interval controls now use the same themed dropdown component as the other settings screens. The native OS popup is gone. The underlying localStorage keys and Rust cleanup settings are unchanged.

A regression test covers the repeat and autoplay boundary. Run `npm test` to check it.

Release build is the same unsigned current user Windows x64 NSIS installer as before.
