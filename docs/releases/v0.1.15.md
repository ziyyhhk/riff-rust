**Everything your friends reported, fixed and verified — plus a security-audit pass on both the frontend and backend.**

What you saw:

- **Profile picture & banners now work.** Picked images/videos are stored as Tauri asset:// URLs the webview can render (scope `**` in assetProtocol), and old `file://` values are migrated at render time.
- **Banner settings fully work.** Click a thumb, toggle switches, pick a banner file, fit/blur/opacity/fade, reset — all persist and render.
- **Settings sidebar never overlaps.** The Account row was a sticky element that collapsed onto About/Advanced; it now flows with the rest.
- **Language switching actually applies.** `/api/i18n-batch` is implemented (DeepL with your key, otherwise Google gtx with mirror rotation, plus a MyMemory fallback). Selecting a language no longer silently reverts to English.
- **Discord RPC is never silent anymore.** Settings → Integrations → Discord RPC shows live reachability; the toggle drives a real pipe handshake; with Discord running it connects automatically and re-submissions are deduped (no more constant stream of identical updates).
- **Playlist import (Spotify/YouTube/SoundCloud) plays.** Failures surface as errors while all others resolve through YouTube search; Daily Mix tracks resolve by artist+title.
- **Theme / plugin IPC failures no longer crash the loader** (`listThemes`/`listPlugins` failures degrade to an empty list instead of `null.filter` TypeErrors at boot).
- **Download-folder Change/Reset work** (reset argument was missing from the shim invocation).
- **Music-folder change no longer reports failure on success** — it mistook the Tauri response shape.
- **Create-shortcut reports success on success** (same response-shape mismatch).
- **"Check for updates" runs its direct check immediately** instead of hanging the spinner for 6 seconds.
- **Google sign-in gives feedback** instead of a silent no-op before porting.
- **Playlist export actually writes the file** to your download directory (the double-encoded inner JSON is what used to land there) and reports the path.
- **Web cache now re-reads correctly** (the renderer expected an object, the Rust command returned a string — every HomeCache entry was falling back to a network fetch).

Backend fixes from the audit:

- **Proxied streams no longer die after ~8 seconds** — a separate deadline-less HTTP client serves the audio and image proxies (the API client's 8 s deadline used to truncate mid-playback).
- **Local imports (m4a/AAC/webm/ogg) can now be transcoded and played** (id-length cap was rejecting them).
- **Word-level lyrics work for plain-LRC NetEase tracks**, not just YRC; misses are not cached for 24 h anymore, and NetEase moved to HTTPS.
- **ffmpeg transcodes are timeout-guarded** and only usable outputs are cached; a single stalled track no longer holds the cache queue for minutes.
- **NetEase + i18n fall back gracefully** on rate-limited networks; `apply_offset` no longer emits invalid centis.

Old releases were removed; v0.1.14 and older are gone. v0.1.15 is the only installed release.
