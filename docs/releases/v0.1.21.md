## Riff Rust 0.1.21

Synced the upstream Riff v0.7.6 fixes into the Rust fork without losing the custom features (gapless, lucky button, queue dedup, universal import, sidebar animation).

Local files no longer stutter. Long lists (local library, big playlists, favorites, history) now render only the visible slice plus a small overscan instead of building every row at once. Scrolling a 1000-track library stays smooth. Search keeps full rendering because its rows can be replaced by paged results.

Add local files straight into a playlist. The playlist header has a new "Add local" button. It opens the file picker, reads tags and cover art natively, and adds the tracks to the open playlist. Duplicates are caught first.

Add files / Add folder actually work now. In the local view these buttons previously handed raw paths to the merger and added nothing. They now return proper track objects (title, artist, album, duration, cover, playable URL) and populate the library.

Duplicate protection when adding to a playlist. If a song is already in the target playlist you get a confirmation with "Don't add" and "Add anyway", for single tracks and bulk selections. The picker also badges playlists that already contain the selection.

Stream loading fixes from upstream. `resetSource=1` bypasses the resolve cache for a forced re-resolve, and short-lived HLS playlist URLs are no longer cached stale, so a replayed HLS track re-resolves instead of dying on an expired signature.

Repo housekeeping. Release notes, the handoff/porting docs and the artwork moved under `docs/`. The repository root is now just code and config, not a pile of loose notes and images.

Memory, measured the same way as before (`npm run measure`). The main `riff-rust.exe` process sits around 3 to 6 MB. The whole WebView2 process tree idles anywhere from ~20 to ~50 MB depending on what the home feed has cached, and spikes higher while loading or playing before settling. The app process itself is a few MB; a guaranteed under-20 MB whole tree is not a real claim because the OS browser is the floor.

Installer is unsigned current user, same NSIS setup as before.
