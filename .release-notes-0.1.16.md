Settings dialog fix. The settings backdrop is now fully opaque above every window layer, so scrolling no longer washes it out. The account row scrolls with the other sections and no longer covers the plugins entry. Opening settings from the gear always lands on Interface instead of the last opened category, and the active category highlight stays glued to its row when the settings sidebar scrolls. The accent color picker raises intensity when it is at zero so the chosen color is visible, the shipped default shows the accent instead of a grey palette, and settings sliders use the accent color. Choosing a custom banner or profile picture now renders the selected media and enables the banner toggle when needed. Interface language now translates through a second Google batch endpoint when the main one is throttled, and a failed translation reverts to the previous language instead of silently staying English.
