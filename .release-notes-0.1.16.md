Settings fixes across the board. The settings window is fully opaque above every layer so scrolling no longer washes it out. Opening settings from the gear always lands on Interface instead of the last opened category, and each category opens only its own section. The active category highlight stays glued to its row when the sidebar scrolls, and the sidebar scrollbar is hidden. The accent color picker raises intensity when it is at zero so the chosen color stays visible, the shipped default shows the accent instead of a grey palette, and settings sliders use the accent color. Choosing a custom banner or profile picture now renders the selected media, and choosing a banner enables the banner toggle when it is off. Interface language now translates through a second Google batch endpoint when the main one is throttled, and a failed translation reverts to the previous language instead of silently staying English. The Discord RPC panel reports its connection status and reconnects on demand. Spotify and SoundCloud playlists imported into Riff now play reliably: SoundCloud permalinks that fail to resolve fall back to the same YouTube search used by manual playback instead of timing out. Clicks on the settings sidebar no longer open Account by mistake: the invisible hit layer of the account button had stretched over the whole sidebar.
