Settings fixes across the board. The settings window is fully opaque above every layer so scrolling no longer washes it out. Opening settings from the gear always lands on Interface instead of the last opened category, and each category opens only its own section. The active category highlight stays glued to its row when the sidebar scrolls, and the sidebar scrollbar is hidden. The accidental click of the account row on other settings buttons is fixed: buttons in the sidebar no longer borrow the account row's hit layer. The accent color picker raises intensity when it is at zero so the chosen color stays visible, the shipped default shows the accent instead of a grey palette, and settings sliders use the accent color. Choosing a custom banner or profile picture works, and the supported image formats now include .jfif for anyone whose files use that extension. The Discord RPC now stays meaningful while you browse Riff Rust without playing anything: it reports the page you are on (home, liked songs, albums, queue, a playlist, an album, an artist, or what you searched for) as a rich presence, switches back to listening activity while music plays, and only reports connected after Discord accepts the handshake and the activity. The companion bug where the app claimed connected even when Discord ignored its activity is fixed: a rejected activity now flips the indicator back to disconnected and logs the reason. The window and taskbar icon is the transparent emblem, with the black corners gone. Heavy blurred background artwork and ambient blobs now pause when the window is blurred or hidden, and the WebView2 host is limited to a single renderer process, which cuts several hundred MB of memory footprint and dramatically lowers idle CPU. The settings writes are flushed to disk on quit so toggles and settings stick across restarts, and the tray quit path and the close button flush the storage map synchronously. Spotify and SoundCloud playlists imported into Riff play reliably: SoundCloud permalinks that fail to resolve fall back to the same YouTube search used by manual playback instead of timing out. Interface language now translates through a second Google batch endpoint when the main one is throttled, and a failed translation reverts to the previous language instead of silently staying English. Memory use is much lower now: list and card artwork is fetched at screen size instead of full resolution, WebView2 runs in its low memory mode with a low memory usage target, and the app uses software compositing so the GPU process stays tiny. Idle memory measures about 93 MB in Task Manager, down from about 168 MB, and memory while a track plays stays near 134 MB.
