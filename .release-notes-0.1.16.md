Settings fixes across the board. The settings window is fully opaque above every layer so scrolling no longer washes it out. Opening settings from the gear always lands on Interface instead of the last opened category, and each category opens only its own section. The active category highlight stays glued to its row when the sidebar scrolls, and the sidebar scrollbar is hidden. The accidental click of the account row on other settings buttons is fixed: buttons in the sidebar no longer borrow the account row's hit layer. The accent color picker raises intensity when it is at zero so the chosen color stays visible, the shipped default shows the accent instead of a grey palette, and settings sliders use the accent color. Choosing a custom banner or profile picture works again: the file picker call used the wrong argument shape and silently failed for every file and folder button in the app. The settings writes are flushed to disk on quit so toggles and settings stick across restarts. The tray quit path and the close button flush the storage map synchronously. Spotify and SoundCloud playlists imported into Riff play reliably: SoundCloud permalinks that fail to resolve fall back to the same YouTube search used by manual playback instead of timing out. Interface language now translates through a second Google batch endpoint when the main one is throttled, and a failed translation reverts to the previous language instead of silently staying English. The Discord RPC panel reports its connection status and reconnects on demand. The app icon is the new artwork.
