## Settings

* The settings panel is fully opaque above every layer, so scrolling never washes it out.
* The gear always opens on Interface, and each category opens only its own section.
* The active category highlight stays with its row while the sidebar scrolls, and the sidebar scrollbar is hidden.
* Sidebar buttons no longer borrow the account row hit layer, so clicking them cannot open your profile by mistake.
* The accent color picker raises intensity when it sits at zero, the shipped default shows the accent instead of a grey palette, and sliders follow the accent color.
* Custom banner and profile picture choices work, and `.jfif` is accepted alongside the usual image formats.
* Settings writes are flushed to disk on quit, and the tray quit path and the close button flush the storage map synchronously, so toggles stick across restarts.
* Opening settings is instant: the interface stylesheet is written once instead of rebuilt on every open, and the scroll reset happens before the panel appears.
* Dialogs opened from settings, including the clear cache confirmation, render above the panel instead of behind it.

## Discord presence

* Browsing now shows as rich presence: the home page, liked songs, albums, the local library, playback history, the queue, a playlist, an album, an artist, or what you searched for.
* Presence switches to the listening card while music plays and back to browsing when it stops.
* The app reports connected only after Discord accepts both the handshake and the activity. A rejected activity flips the indicator back to disconnected and logs the reason.
* Presence moves through one polling thread that writes every track change and browse update immediately, and sends the activity again once Discord reports READY.
* Browsing and search presence uses the Riff logo instead of the wordmark image, so the card matches the app icon.

## Imports and language

* Spotify and SoundCloud playlists imported into Riff play reliably. SoundCloud permalinks that fail to resolve fall back to the same YouTube search used by manual playback instead of timing out.
* Interface language translates through a second Google batch endpoint when the main one is throttled, and a failed translation reverts to the previous language instead of silently staying English.

## Memory and CPU

* Idle memory measures about 93 MB in Task Manager, down from about 168 MB, and playback stays near 134 MB.
* List and card artwork is fetched at screen size instead of full resolution.
* WebView2 runs in low memory mode with a low memory usage target, and the host is limited to a single renderer process.
* Software compositing keeps the GPU process small.
* Heavy blurred background artwork and ambient blobs pause when the window is blurred or hidden.
* Decorative animations stop while nothing is playing and resume the moment playback starts, which took idle CPU from about twelve percent of a core to about one percent.

## Appearance

* The window and taskbar icon is the transparent emblem, with the black corners gone.
