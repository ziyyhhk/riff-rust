**Lyrics are back, and lighter.**

- The karaoke "album cover only" toggle hid every lyric line; combined with the full-screen-only default, no lyrics were visible anywhere. That toggle is auto-reset once on upgrade, so karaoke shows the lyric lines again (you can re-enable it in the overlay).
- Lyric highlighting no longer re-renders at 60 FPS; it now updates at ~12.5 Hz, which noticeably cuts stutter on slower machines.
- Discord Rich Presence actually lands now: the pipe handshake no longer blocks the writer thread, identical repeat updates are deduplicated, and the app logs `discord activity sent` when Discord acknowledges.
- YouTube first plays still transcode on the fly (~2–5 s once, then instant); fresh playlist tracks prefetch in the background.
- Old releases were removed from GitHub; this is the only release going forward.

If you still don't see lyrics after this, it's the Settings → Lyrics row, not the build — check "Online lyrics" is on and "Fullscreen lyrics only" is off, or toggle the image button in the karaoke view.
