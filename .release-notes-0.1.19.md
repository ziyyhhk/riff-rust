## Riff Rust 0.1.19

This release is mostly about fixing things that looked like they worked.

Custom data directory works now. Choosing a data folder used to copy your files once and then quietly keep using the default location. The override now lives in a fixed pointer file in AppData and takes effect on the next launch.

Plugins actually run. Enabling one used to do nothing, it looked enabled but nothing executed. Plugins now load and run the same way they did on upstream.

Saving default settings works. The app used to show a button that saved nothing. It now writes the file and tells you where it went.

Offline library shows real titles and artists read from the files instead of random video ids.

Charts fall back correctly. When a chart fails to load the app falls back to the cached chart or hides the section instead of showing success with an empty list.

Playback is steadier. Stream failures get a readable message and the retry path is more reliable. Tracks you played before still start instantly.

Several crashes on image and audio routes are gone. Those routes now return a clean error instead of dropping the connection.

Memory use is at parity with 0.1.18 measured the same way. The visible window sits around 171 to 278 MB across runs on this machine, 0.1.18 measured 214 MB the same way. Minimized to tray it trims down to roughly 145 to 150 MB. The riff rust process reads about 36 to 40 MB visible and about 4 MB in tray. Anyone promising under 40 MB for a WebView2 app is measuring something else, visible window memory belongs to WebView2 not this app.

Smaller wins in the renderer too. Lists and sidebars now decode smaller artwork copies, and off screen rows skip drawing entirely.

Install is the same NSIS installer as always. If you are on 0.1.18 the app updates itself on launch, or grab this installer directly.
